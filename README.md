## Состав

| Путь | Назначение | Работа |

## Быстрая проверка

```bash
scripts/audit.sh; echo $?          # 0 — конфигурация соответствует требованиям
scripts/deploy.sh --dry-run        # план доставки, сервер не изменяется
scripts/deploy.sh                  # доставка + проверка HTTPS с проверкой сертификата
```

Сценарий `deploy.sh` требует: псевдоним `devops` в `~/.ssh/config`, файл
`~/devops.crt` (копия сертификата, полученная по SSH), утилиту `rsync`.
